# ПМ.02 Арифметические выражения на C#

## Запуск на ПК

Распакуй ZIP. Открой файл PM02_Arithmetic.csproj в Visual Studio 2022 с поддержкой .NET 8 и нажми Ctrl+F5. Если установлен .NET 8 SDK, можно открыть терминал в папке проекта и выполнить `dotnet run`.

Ожидаемый вывод:

```text
2 + 2 = 4
3 * 3 = 9
((18 + 6) * (15 - 7) - 36) / 6 + 4 * 5 = 46
```

## Загрузка на GitHub с телефона

1. Сохрани архив в приложение «Файлы» и нажми на ZIP, чтобы распаковать его.
2. Открой https://github.com/consgrie/- в Safari под своим аккаунтом.
3. На пустой странице репозитория нажми **uploading an existing file**. Если файлы уже есть, выбери **Add file → Upload files**.
4. Выбери из распакованной папки Program.cs, PM02_Arithmetic.csproj и README.md. Нажми **Commit changes**.
